## 功能一览

| 功能 | 说明 |
| --- | --- |
| 屏蔽聊天 | 名单中的人发的局内聊天不会出现在你的聊天历史和头像气泡里 |
| 屏蔽表情（可选） | 同时屏蔽名单中的人发的表情 |
| 自动回复 | 名单中的人每发一条聊天，自动回一句你预设的话 |
| 最近发言者 | 自动记录最近 30 位发言者，一键加入屏蔽/回复名单 |
| 频率保护 | 冷却时间、每分钟上限、服务端限流（RATE）自动退避 |
| 统计 | 显示累计屏蔽条数、回复条数 |

适用范围：所有 `*.xiaolubao.com` 下的游戏节点（如 hk.xiaolubao.com、weishu.xiaolubao.com 等）。聊天只存在于对局中，所以功能也只在对局中起作用。

## 安装

### 方式一：油猴脚本（推荐）

1. **安装脚本管理器**（任选其一）：
   - **Tampermonkey**：[Chrome 应用商店](https://chromewebstore.google.com/detail/dhdgffkkebhmkfjojejmpbldmpobfkfo) / [Edge 加载项](https://microsoftedge.microsoft.com/addons/detail/iikmkjmpaadaobahmlepeloendndfphd) / [Firefox 附加组件](https://addons.mozilla.org/firefox/addon/tampermonkey/)
   - **Violentmonkey**：[Chrome 应用商店](https://chromewebstore.google.com/detail/jinjaccalgkegednnccohejagnlnfdag) / [Edge 加载项](https://microsoftedge.microsoft.com/addons/detail/eeagobfjdenkkddmbclomhiblgggliao) / [Firefox 附加组件](https://addons.mozilla.org/firefox/addon/violentmonkey/)
2. **Chrome / Edge 额外步骤**（Manifest V3 新规）：较新版本的浏览器要求为脚本管理器显式开启权限，否则脚本不会运行：
   - Chrome 138 及以上：打开 `chrome://extensions` → 找到 Tampermonkey →「详情」→ 打开 **「允许运行用户脚本」（Allow User Scripts）**。
   - 较早的 Chrome / Edge：打开 `chrome://extensions`（Edge 为 `edge://extensions`）右上角的 **「开发者模式」**。
   - 如果脚本管理器图标上提示需要开启权限，按它的提示操作即可。Firefox 无需此步骤。
3. **点击一键安装链接**：[xiaolubao-chat-guard.user.js](https://raw.githubusercontent.com/lakeofsky347/xiaolubao-chat-guard/main/xiaolubao-chat-guard.user.js)，在弹出的安装页点「安装」。
4. **刷新已打开的游戏页面**。脚本必须在页面最开始时加载，安装前打开的页面不会生效。

### 方式二：Chrome / Edge 扩展

1. 下载本仓库（右上角 Code → Download ZIP）并解压。
2. 打开 `chrome://extensions`（Edge：`edge://extensions`），开启右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择解压后的 **`extension`** 文件夹。需要 Chrome / Edge 111 及以上。
4. 刷新游戏页面。设置面板在点击工具栏的扩展图标后弹出（界面与油猴版一致，设置用 `chrome.storage.sync` 保存）。

> 不要同时启用油猴脚本和扩展，否则会重复处理消息（例如回复两次）。

## 快速上手

1. 打开任意游戏节点，**进入一局对局**（大厅里没有聊天）。
2. 打开设置面板：
   - 油猴版：游戏页按 **Alt+G**；或点浏览器工具栏的 Tampermonkey/Violentmonkey 图标 → **「打开聊天卫士设置」**。再按一次 Alt+G 或点面板右上角 **×** 关闭。
   - 扩展版：点工具栏上的扩展图标。
3. 等有人发言后，他会出现在面板底部的 **「最近发言者」** 列表，格式为「昵称：最近一句话」（鼠标悬停可看 playerId）。
4. 点他右边的 **「屏蔽」**，之后他的聊天就看不到了；点 **「回复」**，之后他每发言一次（在冷却和上限允许时），你会自动回一句预设的话。
5. 拖动面板标题栏可以移动面板，位置会被记住。

## 设置项说明

所有设置自动保存、立即生效，无需刷新。油猴版的设置在所有 `*.xiaolubao.com` 节点之间共享。

### 屏蔽

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 启用屏蔽（总开关） | 开 | 关闭后名单保留但不屏蔽任何人 |
| 同时屏蔽其表情 | 关 | 开启后名单中的人发的表情也会被屏蔽 |
| 屏蔽名单 | 空 | 见下方「名单匹配规则」。点条目右侧「移除」可删除 |

### 自动回复

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 启用自动回复 | 开 | 总开关。名单为空时不会回复任何人 |
| 回复名单 | 空 | 只对名单中的人自动回复 |
| 文案 | `说得对，下次别说了` / `你开心就好` / `嗯嗯好的呢` | 每行一条。游戏单条聊天限 20 字，超出部分自动截断（按字符计，一个 emoji 算一个）。空行会被忽略；全部为空时不会回复 |
| 方式 | 随机 | **随机**：每次随机挑一条；**轮流**：按顺序依次使用 |
| 冷却（秒） | 8 | 两次自动回复之间至少间隔这么久。面板可设 3–600 |
| 每分钟上限 | 4 | 任意 60 秒内最多自动回复几次。面板可设 1–10 |

其他固定行为（不可设置）：
- **不回复自己**：根据登录信息识别自己的 playerId，取不到时按你的昵称识别。
- **随机延迟**：触发后等待 0.6–1.5 秒再发送，显得不那么机械。
- **限流退避**：如果服务器对自动回复返回限流错误（RATE），暂停自动回复 15 秒；之后再次被限流则暂停时长翻倍（30 秒、60 秒……），最长 5 分钟；一旦发送成功，下次退避重新从 15 秒算起。
- 同一个人可以同时在屏蔽和回复名单里：你看不到他的话，但仍会自动回复他。

### 名单匹配规则

- 通过「最近发言者」的按钮添加：记录 **playerId**（同时保存昵称用于显示），最准确，对方改名也有效。
- 手动在输入框添加：
  - 输入内容是 **8 位及以上、只含字母/数字/`-`/`_`** 的，按 **playerId** 匹配；
  - 否则按 **昵称** 精确匹配（忽略首尾空格）。昵称可能重复、被冒用或被修改，建议优先用 playerId。
- 名单中显示为「昵称（playerId）」的条目只按 playerId 匹配，不会误伤同名的人；显示为「昵称：xxx」的条目按昵称匹配。

### 最近发言者

- 记录最近 30 位**别人**（不含自己）的 playerId、昵称和最近一句话（最多 40 字），同一人只保留最新一条。
- 被屏蔽的人发言也会出现在这里，方便你随时移除。
- 「清空」按钮清空该列表（不影响名单）。

### 统计

面板标题栏显示「屏蔽 N 回复 N」，扩展版显示「已屏蔽 N · 已回复 N」：
- 屏蔽数：被拦下的聊天和表情总条数；
- 回复数：脚本发出的自动回复条数（不代表服务器一定接受了）。

统计为累计值，跨页面保留，目前面板上没有清零按钮。

## 工作原理

游戏客户端与服务器之间通过一条 WebSocket 连接 `wss://<节点域名>/ws` 收发 JSON 消息：

| 方向 | 消息 | 主要字段 |
| --- | --- | --- |
| 服务器 → 你 | `m.chat`（聊天） | `playerId`、`name`、`text` |
| 服务器 → 你 | `m.emote`（表情） | `playerId`、`id` |
| 你 → 服务器 | `g.chat`（发送聊天） | `text`、`rid`（请求编号） |

脚本在页面开始加载时（`document-start`）把一段代码注入到**页面自身的上下文**（油猴版用 `<script>` 注入，失败时退回 `unsafeWindow`；扩展版用 `world: "MAIN"`），替换 `window.WebSocket`，并且只处理路径为 `/ws` 的连接：

1. 收到 `m.chat` / `m.emote`，如果发送者在屏蔽名单里，就阻止游戏收到这条消息；
2. 收到 `m.chat`，如果发送者在回复名单里且满足冷却/上限/退避条件，就通过同一连接发送 `g.chat`。请求编号 `rid` 使用 2100000000 以上的区间，与游戏自身的编号（从 1 递增）不会冲突；服务器对这些请求的回包会被脚本吞掉，不会在游戏里弹出错误提示；
3. 设置面板运行在脚本管理器的沙箱中，通过 `window.postMessage` 与页面中的代码同步设置、发言者和统计。

所有处理都在本地完成，不收集、不上传任何数据，也不连接除游戏服务器以外的地址。屏蔽只影响你自己的界面，其他玩家照常能看到被屏蔽者的消息。

## 常见问题与排障

**脚本完全没生效（没有屏蔽，面板也打不开）**
- 确认脚本管理器中脚本是「已启用」状态，且当前网址是 `*.xiaolubao.com`。
- Chrome / Edge：确认已按[安装](#安装)第 2 步开启「允许运行用户脚本」或「开发者模式」，这是最常见原因。
- 安装或更新后要**刷新游戏页面**。
- 确认没有同时开着扩展版和油猴版。

**面板打不开**
- Alt+G 在某些系统或输入法下可能被占用，改用脚本管理器菜单里的「打开聊天卫士设置」。
- 面板可能被拖到了窗口边缘：缩放浏览器窗口后再打开；仍不行可以在脚本管理器的「存储」中删除 `panelPos` 项恢复默认位置（右上角）。

**屏蔽没生效**
- 聊天只在对局中出现，大厅里没有可屏蔽的内容。
- 检查总开关是否开启；按昵称匹配时，确认昵称完全一致（对方可能改了名），建议改用「最近发言者」按钮按 playerId 添加。
- 设置修改后对**之后**收到的消息生效，已经显示出来的消息不会被撤回。

**自动回复没发出**
- 检查「启用自动回复」是否开启、对方是否在回复名单、文案是否为空。
- 冷却（默认 8 秒）和每分钟上限（默认 4 次）会跳过部分触发，这是正常现象。
- 可能正处于 RATE 退避中（见下一条）。
- 面板标题栏的「回复」数增加，说明脚本已经发出；如果游戏里看不到你的回复，可能是服务器拒绝了（例如文案触发了屏蔽词），脚本目前不会提示这类失败。

**遇到 RATE（限流）**
- 说明发消息太快。脚本会自动暂停 15 秒起、最长 5 分钟。建议调大冷却、调小每分钟上限。手动聊天也会计入服务器的限流。

**游戏更新后失效**
- 本脚本依赖游戏的消息格式（`/ws` 连接、`m.chat`、`g.chat` 等）。游戏改版后可能失效，请到本仓库查看是否有更新，或提交 Issue。

**如何在控制台查看日志**
- 按 F12 打开开发者工具 →「Console（控制台）」。
- 脚本只在注入失败时输出一条以 `[聊天卫士] 注入失败` 开头的警告；正常运行时不输出日志。
- 可以在控制台输入 `window.__XLB_GUARD_INSTALLED__` 回车：显示 `true` 说明页面中的拦截代码已经加载。
- 在「Network（网络）」→ 筛选「WS」→ 点 `/ws` 连接 →「Messages」，可以看到原始的 `m.chat` / `g.chat` 消息，用来确认对方的 playerId 和回复是否已发出。

## 更新与卸载

- **更新**：油猴版已配置自动更新地址，脚本管理器会定期检查；也可以在脚本管理器中对本脚本手动「检查更新」，或重新点击一键安装链接。扩展版需要重新下载并在扩展页点「重新加载」。
- **卸载**：在脚本管理器中删除本脚本（会一并删除保存的设置）；扩展版在扩展页点「移除」。卸载后刷新游戏页面即可恢复原状。

## 开发

```
xiaolubao-chat-guard.user.js   油猴脚本（构建产物，请勿直接修改）
extension/                     MV3 扩展
  core.js                      屏蔽/回复的核心逻辑（无 DOM 依赖，扩展与油猴共用）
  inject.js                    在页面上下文中包装 WebSocket
  bridge.js / popup.*          扩展的存储同步与弹窗界面
userscript/
  ui.js                        油猴版的注入、GM 存储与悬浮面板
  build.js                     构建脚本
test/run.js                    单元与集成测试
```

- 构建油猴脚本：`node userscript/build.js`（把 `extension/core.js`、`extension/inject.js`、`userscript/ui.js` 拼成单文件；版本号取自 `extension/manifest.json`）。
- 运行测试：`node test/run.js`（需要 Node.js 18+）。测试在本地模拟浏览器、WebSocket 和油猴 API，**不会连接任何服务器**，覆盖名单匹配、截断、冷却、每分钟上限、轮流、RATE 退避、rid 处理、不回复自己，以及油猴脚本的注入与 GM 存储。
- 修改代码后请先构建再运行测试，并一并提交构建产物。
