# 卫戍协议 聊天卫士（Chrome / Edge MV3 扩展）

适用于《卫戍协议：盟约》网页版各节点（`*.xiaolubao.com`，如 hk.xiaolubao.com）的**局内聊天**：
- **屏蔽**：按 playerId 或昵称屏蔽某人的聊天（可选同时屏蔽其表情）。被屏蔽的消息在到达游戏界面前即被丢弃，聊天历史和头像气泡都不会出现。
- **自动回复**：对指定的人自动回一句话，文案可自定义（随机/轮流），自动截断到 20 字，带冷却和每分钟上限。

## 安装
1. 解压 `xiaolubao-chat-guard.zip`（或直接使用 `extension/` 文件夹）。
2. Chrome 打开 `chrome://extensions`（Edge：`edge://extensions`），打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择解压后的文件夹。需要 Chrome/Edge 111+（支持 `world: "MAIN"`）。
4. **安装后刷新已打开的游戏页面**（脚本需在页面最早阶段注入）。

## 使用
- 点工具栏图标打开设置面板，所有设置自动保存并实时生效（跨设备同步）。
- 「最近发言者」：进入对局后，别人发言会出现在列表中，点「屏蔽」或「回复」即可一键加入名单（按 playerId，最准确）。
- 也可手动输入：形如 ID（≥8 位字母/数字/-/_，无空格）的按 playerId 匹配，否则按昵称精确匹配。昵称可能被他人冒用或改名，推荐用 playerId。
- 自动回复设置：冷却默认 8 秒（最低 3 秒），每分钟上限默认 4 条；不会回复自己；服务端返回限流（RATE）时自动退避 15 秒起，指数增长到最长 5 分钟。

## 工作原理
- `core.js + inject.js` 在页面主环境（MAIN world）于 document_start 运行，包装 `window.WebSocket`，只处理路径为 `/ws` 的游戏连接：
  - 收到 `m.chat` / `m.emote` 时比对黑名单，命中则阻止页面收到该消息。
  - 命中回复名单时，经 0.6–1.5 秒随机延迟后在同一连接发送 `{t:"g.chat",text,rid}`。rid 使用 2100000000 以上的私有区间（客户端 rid 从 1 自增，不会撞号），服务端对这些 rid 的回包会被扩展吞掉，不会让游戏弹出错误提示。
- `bridge.js`（隔离环境）负责 `chrome.storage` 与页面脚本之间的设置同步、记录发言者与统计。
- 不收集、不上传任何数据；只申请 `storage` 权限。

## 风险提示（请务必阅读）
- 本扩展修改游戏客户端的网络行为。自动发送消息可能违反游戏/社区规则，**可能导致禁言或封号**，后果由使用者自负。
- 请勿用于辱骂、骚扰他人；建议文案保持友善，并保留冷却与频率上限。
- 游戏更新可能改变协议（如 `m.chat` / `g.chat` 字段），届时扩展可能失效或行为异常。
- 屏蔽只作用于你自己的界面，对方和其他玩家仍能看到其消息。
